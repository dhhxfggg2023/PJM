# PJM Link（电脑端）

手机上的「PJM」把库里的文件通过 USB 线搬到电脑，全程走 adb 隧道，**不经过 Wi-Fi、不消耗手机流量、手机不产生副本**。

## 用法

1. 手机：设置 → 关于手机 → 连续点版本号打开开发者选项 → 打开 **USB 调试**；插上数据线，在手机上点「允许」。
2. 手机：PJM → 设置 → 传输到电脑 → 打开「开启传输服务」。
3. 电脑：双击本文件夹里的 `PJM-Link.cmd`，窗口显示「设备：已连接」后点 **接收手机文件**。
4. 文件会进 `PJM-Transfer\<分类>\<日期>\`，同名自动加 ` (2)`。

## 这个文件夹

- 可以整体剪切到任意位置（D:\、E:\、移动硬盘、U 盘），数据跟着走；
- 不写注册表、不写 AppData、不开机自启、不常驻后台，关窗口就退出；
- `adb\` 里是自带的 adb，不依赖你电脑上装过 Android 开发环境；
- `PJM-Link.log` 是日志（超过 5MB 自动清空），出问题发这个文件。

## 特性

- **断点续传**：先写 `PJM-Transfer\.tmp\<名字>.part`，收完才原子改名，不会留下半截文件；
- **只传没传过的**：账本 `PJM-Transfer\.pjm-transfer.json` 按「相对路径 + 大小 + 修改时间」判重；
- **磁盘格式检测**：窗口会显示 NTFS / exFAT / FAT32 与剩余空间；FAT32 单文件上限 4GB，超了会直接报错；
- 文件名自动清洗 Windows 非法字符、去掉结尾点和空格、限长 120。

## 注意

- 关闭窗口时只移除 adb 隧道，**不会关闭 adb 服务**；
- 手机端需要「传输到电脑」页面打开服务（服务只监听 127.0.0.1，电脑靠隧道接入）；
- 首次运行 Windows 可能提示「未知发布者」，选「更多信息 → 仍要运行」。
