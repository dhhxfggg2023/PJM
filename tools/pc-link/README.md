# PJM Link（电脑端）

手机上的「PJM」通过 USB 线把库里的文件搬到电脑，全程走 adb 隧道，**不经过 Wi-Fi、不消耗手机流量、手机不产生副本**。

## 用法

1. 手机：设置 → 关于手机 → 连续点版本号打开开发者选项 → 打开 **USB 调试**；插上数据线，在手机上点「允许」。
2. 手机：PJM → 设置 → 传输到电脑 → 打开「开启传输服务」。
3. 电脑：双击本文件夹里的 `PJM-Link.cmd`，窗口显示「设备：已连接」。
4. 手机：在同一页选好要传的日期（不选就是全部），点「开始传到电脑」。
   文件由手机逐个推过来，电脑只负责落盘；两边都能看到进度。
5. 文件会进 `PJM-Transfer\<分类>\<日期>\`。

## 这个文件夹

- 可以整体剪切到任意位置（普通文件夹、移动硬盘、U 盘都行），数据跟着走；
- 不写注册表、不写 AppData、不开机自启、不常驻后台，关窗口就退出；
- `adb\` 里是自带的 adb，电脑上不需要装过 Android 开发环境；
- `PJM-Link.log` 是日志，遇到问题时把这个文件发出来。

## 特性

- **按 uuid 认文件**：同一个文件（改名、换入库日期都还是同一个）重复点「开始」，电脑上不会再出现第二个副本。推送账本 `PJM-Transfer\.pjm-push.tsv` 按 `分类|uuid` 记着收过哪些（手机推送路径）。
- **先写临时文件再改名**：收完才落成正式文件名，中途断线不会留下半截文件。
- **断点续传**：由电脑发起拉取时，先写 `PJM-Transfer\.tmp\<按内容身份派生的短哈希>.part`，收完再原子改名；同名不同内容的文件不会互相续传，中断超过 24 小时的陈旧 `.part` 会在启动时清理。拉取账本 `PJM-Transfer\.pjm-transfer.json` 按 `源路径|大小|修改时间` 记着收过哪些（电脑拉取路径）。
- **进度两边同步**：手机端显示已传数量、字节、速度、剩余；电脑窗口同步显示当前文件和进度。
- **磁盘格式检测**：窗口会显示 NTFS / exFAT / FAT32 与剩余空间（每 5 秒刷新）；FAT32 单文件上限 4GB，超了会在写盘前直接报错。
- 文件名自动清洗 Windows 非法字符、去掉结尾点和空格、限长 120。

## 注意

- 关闭窗口时只移除 adb 隧道，**不会关闭 adb 服务**；
- 手机端服务只监听 127.0.0.1，电脑靠隧道接入，同一网络里的其他设备连不上；
- 手机端每次开启传输服务都会生成随机令牌并写到自己外部私有目录，本工具会自动用 `adb shell cat` 读取并带上；**手机端 2.1.6 及以上必须配套本版工具**，旧版工具会因为缺令牌被拒绝（手机端会提示「请更新 PJM-Link」）；
- 首次运行 Windows 可能提示「未知发布者」，选「更多信息 → 仍要运行」。
